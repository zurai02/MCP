Add the MCP to Claude

Pick where you use Claude, copy one thing, restart. It takes about two minutes.

You need Node.js 18 or newer. Check by opening a terminal and running node -v. If it says command not found, install it from nodejs.org first. This works in Claude Desktop and Claude Code. The claude.ai website and phone app can't run it, because they only connect to servers hosted online.

Install

  1. Open the config file. In Claude Desktop go to Settings, then Developer, then Edit Config. This shows claude_desktop_config.json.
  2. Add the server. If the file is empty, paste the config below. If it already has content, use the merger further down so you don't break it.
  3. Save, then fully quit Claude and open it again. On Windows, quit from the system tray, because closing the window isn't enough.
  4. Check it loaded. Open a new chat and look for roblox-luau in the tools menu.
claude_desktop_config.json
{
  "mcpServers": {
    "roblox-luau": {
      "command": "npx",
      "args": ["-y", "github:zurai02/MCP"]
    }
  }
}
macOS file location~/Library/Application Support/Claude/claude_desktop_config.json
Windows file location%APPDATA%\Claude\claude_desktop_config.json

Edit Config in the app is the easiest way to find it.

  1. Run this in your terminal. The two dashes before npx are required.
  2. Check the connection. Run claude mcp list. You should see roblox-luau marked as connected. Inside a Claude Code session, /mcp shows the same.
  3. Use it everywhere (optional). Add --scope user to make it available in all your projects, not only the current one.
terminal
claude mcp add --transport stdio roblox-luau -- npx -y github:zurai02/MCP
terminal, all projects
claude mcp add --transport stdio --scope user roblox-luau -- npx -y github:zurai02/MCP

Check it works

  • Tools appear. You see roblox-luau in the tools menu, with luau_guidelines, ui_pattern, studio_guide, gameplay_recipe, review_luau and list_topics.
  • A real request. Ask: "Use list_topics, then write me a kill brick." Claude should call the tools and answer with a script that starts with --!strict.
  • Cheap lookups. Ask: "Search the guides for how to validate remote arguments." Claude should call search_knowledge and fetch one section, not a whole file.
  • The review tool. Paste some old Luau that uses wait() and ask Claude to run review_luau on it. It should flag wait() and suggest task.wait().

Let Claude edit Studio directly

Roblox Studio has its own MCP server. Turn it on next to this one. This MCP brings the Roblox know-how and checks, and Studio's server lets Claude read, edit and test scripts in your open place.

  1. Open your place in Roblox Studio and open Assistant.
  2. Open the three-dot menu, then Manage MCP Servers.
  3. Turn on "Enable Studio as MCP server".
  4. Under Quick Connect, turn on Claude Desktop or Claude Code. A green indicator means it is connected.
  5. Restart Claude. If Claude is not listed, restart Studio first.
Be careful, this can change your game. Studio's server can read and edit the place you have open. Save a version or work on a copy first, keep each request small, and use Ctrl+Z if you don't like a change. If you have several Studio windows open, check Claude is working in the right one. Menu names can change between Studio versions, so if you don't see them, look for MCP in Assistant's settings or check Roblox's documentation.

Something's wrong

The tools never show up (Claude Desktop)
  • Quit Claude completely and open it again. Closing the window is not enough.
  • The config must be valid JSON: matching braces, double quotes, and commas between entries but not after the last one. Run it through the merger above to catch mistakes.
  • Run node -v in a terminal. If Node is missing or older than 18, install a newer one.
  • Open Settings, then Developer. It lists local servers and shows if one failed, with a link to its log.
"npx not found" or "spawn npx ENOENT"

Claude can't find Node. Install Node.js 18 or newer, then fully restart Claude. On Windows you may need to restart the computer so the new path is picked up.

It says connected but the first start was slow

The first start downloads the server from GitHub, so it can take several seconds. Later starts are quicker.

Claude Code shows "Failed to connect"
  • Run claude mcp get roblox-luau. It prints the error.
  • Make sure the command has the two dashes before npx.
  • Remove it and add it again: claude mcp remove roblox-luau, then run the add command.
Can I use it on claude.ai in my browser or on my phone?

Not this version. The website and phone app only connect to servers that are hosted online. This one runs on your own computer. Use Claude Desktop or Claude Code.

Claude gives me code but doesn't change my place
  • Studio's own MCP server is separate from this one. Turn it on as described above.
  • Check the green connected indicator in Studio's Manage MCP Servers, then restart Claude.
  • Make sure the place you want changed is the one open in Studio.
How do I remove it?

Claude Desktop: delete the roblox-luau entry from the config file and restart Claude. Claude Code: run claude mcp remove roblox-luau.
