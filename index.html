local part = script.Parent

function onTouch(hit)
    local humanoid = hit.Parent:FindFirstChild("Humanoid")
    if humanoid then
        humanoid.Health = 0
    end
end

part.Touched:connect(onTouch)
  • Global function and deprecated :connect
  • No types, so mistakes show up at runtime
  • Fires over and over on a single touch
--!strict
local Players = game:GetService("Players")

local part = script.Parent :: BasePart
local COOLDOWN = 1
local lastHit: {[Player]: number} = {}

part.Touched:Connect(function(hit: BasePart)
    local character = hit.Parent :: Model?
    local player = character and Players:GetPlayerFromCharacter(character)
    local humanoid = character and character:FindFirstChildOfClass("Humanoid")
    if not player or not humanoid then return end

    local now = os.clock()
    if now - (lastHit[player] or 0) < COOLDOWN then return end
    lastHit[player] = now

    humanoid.Health = 0
end)

Players.PlayerRemoving:Connect(function(player: Player)
    lastHit[player] = nil
end)
  • Strict mode, typed, services fetched once
  • Only real players trigger it, with a per-player cooldown
  • Cleans up after players leave

What it covers

Four areas where generic answers fall apart in Roblox, and where this MCP keeps Claude on track.

Luau scripting

Modern, strict Luau: type annotations, the task library, clean module structure, events instead of polling, and the client/server split done properly with RemoteEvents and RemoteFunctions that validate what the client sends.

  • --!strict
  • ModuleScripts
  • RemoteEvents
  • DataStores
  • task.spawn
  • Signals

2D apps and UI

Menus, HUDs, inventories, shops and dialogs built from ScreenGuis and layout objects. Sizing uses scale first and offset second, so interfaces hold up on phones, tablets and wide monitors.

  • ScreenGui
  • UIListLayout
  • UIGridLayout
  • UIAspectRatioConstraint
  • TweenService
  • Mobile safe areas

Building and gameplay

Parts, models, spawners, doors, pickups, obstacle courses and round systems, with scripts organised so you can duplicate and tweak them without breaking everything else.

  • Models
  • CollectionService tags
  • Raycasting
  • Attributes
  • Round loops
  • Leaderstats

Studio workflow

Claude knows where each script belongs (ServerScriptService, ReplicatedStorage, StarterGui, StarterPlayerScripts) and tells you where to put it. It also reads Output errors with you and fixes the actual cause.

Add it to Claude

Connect the MCP once and it is available in every chat that has it switched on.

  1. Open Claude Desktop, go to Settings, then Developer, then Edit Config. This opens claude_desktop_config.json.
  2. Paste the config from this page and save it. If the file already has mcpServers, add roblox-luau inside it.
  3. Fully quit and reopen Claude, then start a chat and ask for some Luau.
claude config
{
  "mcpServers": {
    "roblox-luau": {
      "command": "npx",
      "args": ["-y", "github:zurai02/MCP"]
    }
  }
}

Needs Node.js 18 or newer. The first start downloads the server from GitHub, so it can take a few seconds. Using Claude Code instead? Run claude mcp add --transport stdio roblox-luau -- npx -y github:zurai02/MCP. Open the full install guide for a config merger and fixes for common problems.

Questions

What is an MCP?

MCP stands for Model Context Protocol. It is a standard way to plug extra knowledge and tools into an AI assistant like Claude, so it can do specialised work better than it would on its own.

Does it edit my game in Roblox Studio directly?

Claude writes the scripts, UI layouts and build instructions, and tells you where they go. You copy them into Studio. Check the GitHub page for anything the current version does beyond that.

Is it only for experienced developers?

No. Beginners can ask for a finished feature and get commented code that explains itself. Experienced developers get strict, structured code they can drop into an existing project.

Does it work for 2D games and apps?

Yes. Roblox UI is 2D by nature, so menus, HUDs, shops and 2D-style mini-games built from GUI objects are a core focus.

Something went wrong. Where do I report it?

Open an issue on the GitHub repository and include the prompt you used and what Claude returned.
